Workflow patterns

Real paths through the product

End-to-end scenarios supported by documented modules — no fabricated customer names or metrics.

Professional services

Weekly billing cycle

Consultants log billable hours against deliverables in the weekly timesheet grid. Managers review utilization on scoped team dashboards. Finance opens the invoice register, pulls approved billable lines into a draft, attaches the PO reference from Sales, and generates a client-ready PDF — every hour traceable to source.

Flow: Timesheet → Utilization dashboard → Invoice register → PDF

Sales & delivery

Won deal to staffed project

A bid moves through pipeline stages with funnel analytics. On win, a purchase order links to the client account. Delivery spawns a project with contract context, assigns members, dates deliverables, and runs staffing agent recommendations — without re-keying client metadata.

Flow: Bid pipeline → Purchase order → Create project → Staffing agent

Payroll operations

Payroll run with readiness

Payroll manager opens the readiness brief — attendance gaps, pending leave approvals, unapproved timesheets, and reimbursement blockers surface before the run. Exceptions route through universal approval. On lock, paychecks publish to employee self-service with audit trail.

Flow: Readiness brief → Exception queue → Approve → Paycheck publish

Managers & PMO

Leave with delivery impact

An employee submits leave. The manager sees team coverage, critical task ownership, and backup suggestions from the Leave Impact Agent before approving. Approved leave syncs to attendance and payroll readiness automatically.

Flow: Leave request → Impact analysis → Approve → Payroll sync

Delivery teams

Sprint staffing decision

A PM reviews team capacity — Overview gauges, Roster availability, Timeline allocation, and Gantt bars — before committing work to the taskboard. Tasks move through workflow stages while WIP analytics and est-vs-actual track sprint health.

Flow: Team capacity → Taskboard → Est-vs-actual

IT & HR

Enterprise identity rollout

Employees sign in with Microsoft Entra ID. HR provisions accounts through the create-employee wizard. Role templates control module visibility. Org configuration inherits down the tree with override indicators for local policy.

Flow: Entra ID SSO → Employee wizard → Role templates → Org config

Mobile workforce

Field time capture

A consultant between client meetings opens mobile timesheet, logs billable hours against the active project, and sees the same week lock and validation hints as the web grid. Managers approve from mobile universal inbox on sync.

Flow: Mobile SSO → Record day → Manager approval

Leadership

Executive portfolio review

CXO opens the executive control tower — portfolio health, workforce utilization, financial exposure, risk heatmap, and approval bottlenecks in one view. Executive Briefing Agent generates a weekly summary with recommended actions and drill-down links.

Flow: Control tower → AI briefing → Action items
