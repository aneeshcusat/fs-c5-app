# Product screenshots

Drop real application captures into this folder using the **exact filenames** below.

Prefer `.webp` (also accepts `.png` / `.jpg`). Until a file exists, the marketing site shows a labelled SVG placeholder with the same stem (`*-placeholder.svg`).

After adding or replacing images, run:

```bash
npm run content:export
# or
npm run build
```
