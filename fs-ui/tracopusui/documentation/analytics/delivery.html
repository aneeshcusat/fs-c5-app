Overview

Delivery analytics composes Project, Task (deliverable), and TaskActivity (work item). Timesheet hours are a different grain. NPD ideas are not tasks.

How to use

1. Naming
Deliverable = Task. Work item = TaskActivity.
2. Tickets vs tasks
Service tickets are a sibling register.
3. Reports catalog
Project → Reports is operational export; this is the analytics pack.
