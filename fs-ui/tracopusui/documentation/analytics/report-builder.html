Overview

Report builder stores definitions that query canonical domains. Project → Reports is the operational catalog. Exports must apply persona masking. This is not a place to paste a CSV as truth.

How to use

1. Respect grants
A report cannot unmask salary for a persona that lacks it.
2. Operational vs ad-hoc
Delivery exports may already exist under Projects → Reports.
3. Schedule is sibling
Do not expect cron on the builder canvas itself if the org uses Scheduled reports.
