Scheduled Reports

Cadence and recipients for saved report definitions — delivery config, not a new metric store.

Scroll to Flowcharts. Scenario: Schedule a saved analytics report.

Cadence

When a saved report leaves the building

Scheduled reports attaches cadence and recipients to definitions you already saved. It does not store a new set of numbers.

Analytics → Scheduled reports Route /analytics/scheduled-reports Org flag scheduledReportsEnabled Executive · Finance · HR · Admin

The job of this console

Pick a definition, set who and when, save. Every send still respects persona masking.

Seat at the table

Executives, finance, HR, admins with scheduledReportsEnabled. Recipients must already be allowed to see the grain.

The working rhythm

Create or edit a schedule, verify a test send, leave it running, audit failures.

Moments that bring you here

Monday pack automation. Month-close appendix. Replacing a manual export. After a builder save.
