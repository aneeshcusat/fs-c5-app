Overview

The executive control tower composes Project, Employee, PurchaseOrder, Task, and commercial views. It is not a warehouse. Analytics hub and domain analytics are sibling grains — this page is the steering cut.

How to use

1. Treat tiles as doors
A red KPI opens a project or contract, not a comment box on the chart.
2. Persona masking
Salary and medical never appear unmasked here.
3. Not Project → Portfolio
Portfolio is delivery grain; this tower is exec grain over the same sources.
