Overview

The hub is a directory of analytics packs. It does not store metrics. Each pack still reads Employee, Project, PurchaseOrder, Task, TaskActivity, or payroll/finance registers.

How to use

1. Hidden packs are flags
Do not assume a missing tile means no data.
2. Not the report builder
Saved ad-hoc reports live on Report builder.
3. Masking follows persona
HR packs still hide pay you cannot see.
