The job of this console

See what is due, open the item, move status, and comment. Create real delivery work on the project when something is missing from the queue.

Seat at the table

Anyone with assignments and myWorkEnabled. Managers still use project list and capacity for other people’s load.

The working rhythm

Filter, open, update, return. End the day with the queue, not a spreadsheet export as the plan.

Moments that bring you here

Monday planning. After standup. A ping that you own a blocked task. Before timesheet Friday — to know which activity to log.

ⓘ
Queue, not ledger
Deliverable means Task. Work item means TaskActivity. My Work does not replace either table.

Overview

My Work is a personal queue over Task and TaskActivity assigned to you. It is not a personal kanban database. Hours still belong on Timesheet.

How to use

1. Do not invent shadow tasks
If work must be planned for the project, create it on the project’s deliverables, then it appears here.
2. Timesheet is elsewhere
Logging hours is People → Timesheets, pointed at the same work item.
3. Pin filters, not copies
Saved filters are convenience, not a second backlog.
