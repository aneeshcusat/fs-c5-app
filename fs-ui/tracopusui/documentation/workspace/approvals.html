Overview

My Approvals aggregates decisions you (or you as delegate) can take across HRMS and delivery domains. Source records stay in their modules; this page is the action inbox, not a second data store.

How to use

1. Start on Pending
Status chips default to Pending. Use All only when auditing history.
2. Narrow the queue
Domain and Priority dropdowns, plus search on requester/subject/module.
3. Act from the drawer
Open a row, review context, approve or reject, then refresh if needed.
4. Save a view
Use saved views for recurring filters (e.g. Leave + High).
