The job of this console

Find a type, install, then leave the catalog for Connections and Mapping. Never treat the listing as a live customer or employee.

Seat at the table

The working rhythm

Browse, install, configure, monitor.

Moments that bring you here

A new CRM. Replacing a CSV drop. Evaluating identity provisioning. After a vendor RFP.

ⓘ
No second source

Overview

Marketplace is the catalog of connector types. It does not store business records. A named vendor project tracker is not a second Project source. Generic work-time adapters cover import/export.

How to use

1. Read the objects
