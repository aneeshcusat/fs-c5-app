Whether the pipe is actually flowing

Overview

Sync monitor is operational health. Jobs run batches. Logs hold detail. Mapping is the contract. Canonical entities remain the business truth when a payload is wrong.

How to use

1. Green before dependent work
Do not start payroll on a stale time export.
2. Retry vs remap
Poison payloads need mapping, not infinite retry.
3. Admin jobs
Platform cron is a different console.
