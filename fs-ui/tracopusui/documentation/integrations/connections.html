The job of this console

Add or rotate an instance, test it, then map. Disable before you yank a secret jobs still use.

Seat at the table

The working rhythm

Create, test, map, schedule jobs, rotate later.

Moments that bring you here

New sandbox. Prod cutover. Credential expiry. After a vendor incident.

Overview

Connections are installed instances. Marketplace is the catalog of types. API access is integration tokens. Admin API keys are platform developer keys. Mapping is the field contract.

How to use

1. Rotate secrets here
Not in Application Config blobs.
2. Disable beats delete
While jobs still reference the instance.
3. Least privilege
Vendor tokens scoped to needed objects only.
