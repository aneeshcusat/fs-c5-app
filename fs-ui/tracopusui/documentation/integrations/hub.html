The job of this console

Pick a connector, finish connection and mapping, run a test, watch sync health. Fix canonical rows when the payload is wrong.

Seat at the table

Integration admins and admins with hubEnabled. Business users do not configure pipes from here.

The working rhythm

Hub → connection → map → test → monitor. Return to the hub only to pick the next pipe.

Moments that bring you here

New vendor. After a failed batch. When Sales asks for Salesforce PO import. When HR asks about ZingHR leave.

ⓘ
Pipes, not source
Native leave, timesheet, and PO flows stay protected. Adapters must not invent duplicate source tables.

Overview

The hub routes to connections, marketplace, adapters, mapping, jobs, and health. Canonical entities remain Employee, Project, PurchaseOrder, Task, TaskActivity, and time. Leave vendor sync must not replace native leave.
