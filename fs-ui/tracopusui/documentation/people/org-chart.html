Read-only view of reporting lines sourced from Employee manager fields — the editable tree lives on Admin org structure.

Read-only tree

The picture of reporting lines already stored

Organization chart draws Employee manager links. It does not store a second org. Reassign on Admin → Org structure.

The job of this console

Find who reports where, then jump to the person or to org structure if a line is wrong.

Seat at the table

HR, managers, executives, admins with orgChartEnabled. Contributors may not get the full company tree.

The working rhythm

Search, inspect, leave. If a box is missing, the manager field is empty — fix it on org structure.

Moments that bring you here

Reorg communication. New manager. Approval chain looking wrong. Onboarding ‘who is my skip?’
