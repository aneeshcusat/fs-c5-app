Login & Registration

Three login modes plus first-time registration flow with mandatory PIN setup and optional biometrics.

Credential, PIN, biometric, and QR registration flows for secure mobile access.

Overview

Login hub includes User Login, 4 Digit PIN, and Biometric tabs depending on registration state.

Screen layout

Flow: Splash → Login hub → first auth → PIN setup → biometric optional → Tasks hub.

Header & filters

Tabs: User Login (always), PIN (after setup), Biometric (device support + PIN setup).
QR scanner: Reads device registration payload from web-generated QR.

Summary & charts

No chart strip; this page is process-focused around authentication and registration states.

Main content & actions

Logout clears session token but preserves device registration and PIN state.

Before you start

ℹ️
SSO users
Use corporate SSO button — local password field disabled.
⚠️
Account lock
Repeated failures lock account — reset via web or IT.

Who uses this screen

All mobile users on first launch or after logout — email/password, SSO, registration, biometric setup, and password recovery.

ℹ️
Mobile authentication
Complete first login on trusted network — SSO and MFA may require corporate connectivity.

Key concepts

Email/password login

Standard credential form matching web Tracopus accounts.

SSO / OAuth

Enterprise single sign-on button when org enables IdP.

Registration

Self-signup or invite-token flow per org policy.

Biometric unlock

Enable after first successful password login.

Forgot password

Email reset link — same backend as web Profile security.

Common mistakes

⚠️
Saving password on jailbroken device
Corporate policy may forbid — use biometric only on managed devices.
⚠️
SSO on guest WiFi
VPN may be required — failure looks like bad password.
⚠️
Skipping biometric on personal phone
Convenience vs shoulder-surfing — enable if policy allows.

FAQ

MFA on mobile?

Supported when web MFA enabled — prompt after password or via SSO.

Session duration?

Refresh token — re-login when expired or forced logout from web.

Multiple accounts?

One account per install — logout to switch.

Biometric without password?

Must login password periodically per OS security.
