Projects Hub

Access project data in the field with quick filters and compact project detail sheets.

Portable project register with chips, search, and bottom-sheet project details.

Overview

Projects hub gives lightweight portfolio access optimized for mobile navigation and quick context lookup.

Screen layout

Controls: Search + chips (Active, Archive, My projects, Favorites).
Body: Scrollable table/list with key columns and row detail sheet.

Header & filters

Search supports project name, account, or identifier fragments.

Summary & charts

Summary cues are intentionally compact on mobile; deep portfolio analytics remain in web Project Dashboard/List.

Main content & actions

Tap any row to open a project detail sheet with expanded fields.

Deep link

Who uses this screen

Mobile users browsing assigned projects — card list, summary detail, status badges, and deep link to full web project.

ℹ️
Projects hub mobile
Quick context before logging timesheet or updating tasks — not full project-details replacement.

Key concepts

Projects hub

Card list of assigned projects with status and account.

Project detail

Summary, team snippet, deliverables shortcut.

Status badges

Delivery state color-coded on cards.

Deep link to web

Open full project-details in browser.

Pull to refresh

Sync project list.

FAQ

Create project on mobile?

No — web project-list CREATE.

Offline project list?

Cached last sync — stale badge when offline.

Notifications per project?

Global task notifications — not per-project mute on mobile.

PO number visible?

On detail if shown on web hero — field parity varies.
