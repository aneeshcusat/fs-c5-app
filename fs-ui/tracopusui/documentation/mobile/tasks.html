Tasks Hub

Task cards, day strip filtering, status chips, and bottom-sheet details for mobile execution.

Default mobile home for day-focused task execution with chips and search.

Overview

Tasks hub is the default landing after mobile login and focuses on daily activity visibility.

Screen layout

Top controls: Work module bar, week range, day strip.
Filters: Search and chips (Completed, Ongoing, Assigned, All).
Body: Task cards and detail sheet.

Header & filters

Search applies when query length is sufficient; chips switch status scopes quickly.

Summary & charts

Compact stats appear in task cards and detail sheets; deeper analytics are available in Insights hub.

Main content & actions

Tap a task card to open details and review identifiers, schedule, people, and duration.

Who uses this screen

Mobile users managing assigned tasks — hub list, pull-to-refresh, detail view, status updates, and offline queue.

ℹ️
Tasks on the go
Primary mobile execution screen — update status in the field before end of day sync.

Key concepts

Tasks hub

List of assigned tasks with status badges and due dates.

Pull to refresh

Sync latest assignments from server.

Task detail

Checklist, comments, attachments on full-screen detail.

Status update

Move task through workflow from mobile.

Offline queue

Changes stored locally until network available.
