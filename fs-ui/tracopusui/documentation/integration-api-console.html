Shared envelope and errors

Success: { "payload": … }. Failure: { "error": [{ "message": "…", "code": "…" }] }.

StatusMeaning
200Success. Entity or list is under payload.
401Missing Bearer, invalid tk_* secret, or FS_INTEGRATION_API_KEY_AUTH_ENABLED=false.
403Missing scope, team mismatch, or developer-portal path with an integration key.
404Unknown id, or a verb/path the server does not map.
500Unhandled server error. Client message is generic.
Token from Tracopus → Integrations → API access. Format tk_{live|test}_{suffix}_{uuid}_{tail}. This page stores credentials in sessionStorage only. Live send uses the browser — host CORS must allow this origin.
