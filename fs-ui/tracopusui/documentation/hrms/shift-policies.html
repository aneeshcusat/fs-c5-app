Overview

Admin → Shift policies stores organization shift calendars. Leave day counting may use these when no employee or jurisdiction override exists. Enable via Application Config / menu access.

How to use

1. Enable the module
Confirm shift policies are enabled for the organization.
2. Create the primary shift
Match your standard work week (e.g. Mon–Fri 09:00).
3. Align leave calendars
Map holiday locations and jurisdictions so leave excludes the right days.
4. Verify with a test leave
Apply a range spanning a weekend and confirm day count.
