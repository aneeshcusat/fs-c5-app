Overview

Anomaly rules, review, and fairness analytics help HR spot unusual patterns without auto-rejecting leave. Screens are registers only — no self-serve write UI; seed via API. Do not store raw sensitive medical content in analytics stores.

How to use

1. Open anomaly rules
Admin → Leave → Anomaly rules register.
2. Review rules
Inspect seeded rules; create/update via API.
3. Work the review queue
Inspect flags; dismiss or act via API.
4. Fairness snapshots
Inspect analytics registers for latency and reject patterns.
