Overview

Timesheet approval adds submit, manager review, conflict resolution, and payroll lock on top of the weekly grid. Delegation may allow acting approvers.

Partial-week flag (timesheetAdditional.partialWeekSubmissionEnabled, default off):

  • Off — employee submits the full week; one pending week; week locked until approve/reject; inbox id WEEK:{id}.
  • On — employee selects days (chips) and may submit multiple batches per week; each batch is a separate approval request (ts_timesheet_submission_model); leftover DRAFT/REJECTED days stay editable; approve/reject by submission; inbox id SUBMISSION:{id}. Fully APPROVED weeks still require reopen before edit.

How to use

1. Employee submits
Full week when partial is off; select day chips and submit a batch when partial is on.
2. Manager reviews
Pending panel or Approvals inbox (week or submission card).
3. Resolve conflicts
Clear overlaps before approve (scoped to the pending week or batch).
4. Lock when ready
Payroll lock after cutoff when the week is fully approved.
