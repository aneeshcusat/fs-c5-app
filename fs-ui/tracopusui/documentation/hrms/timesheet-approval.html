Timesheet Approval

Submit weeks for manager approval, resolve conflicts, and lock payroll periods.

Flowcharts cover submit → approve/reject → lock. Entry grid: Timesheet.

Overview

Timesheet approval adds submit, manager review, conflict resolution, and payroll lock on top of the weekly grid. Delegation may allow acting approvers.

How to use

1. Employee submits
Use Submit on a complete week.
2. Manager reviews
Pending panel or Approvals inbox.
3. Resolve conflicts
Clear overlaps before approve.
4. Lock when ready
Payroll lock after cutoff.
