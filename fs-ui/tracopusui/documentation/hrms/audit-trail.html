Unified Audit Trail

A single luxury timeline for meaningful actions — who did what, when, and on which record — across projects, HR, and profile activity.

Replaces the old History tab data source with a fresh append-only audit stream. Recording is best-effort and never blocks saves or approvals.

Overview

The unified audit system records events when users (or delegates) perform tracked actions. Events appear in Audit tabs on project, purchase contract, deliverable, work item, profile, attendance, timesheet, and leave screens.

Legacy @History and ItemAdditional HISTORY feeds are not shown in the new UI. History starts from go-live when your administrator enables audit writes.

Where to find audit

  • Profile → Account activity — actor timeline + entity filter
  • Project / PO / Deliverable — Comments | Audit tabs
  • Work item — activity register audit mode
  • Attendance — audit feed with deep links to day cells
  • Timesheet week — submit/approve/lock events
  • Leave drawer — request lifecycle with redaction

What is tracked

  • Project, PO, deliverable, work item lifecycle
  • Comments, checklist updates, estimates
  • Employee profile and role changes
  • Attendance mark, approve, reject, removal
  • Leave submit, approve, reject, withdraw
  • Timesheet submit, approve, reject, lock
  • Login and password change (security)

Timeline UI

Each event shows headline, actor, timestamp, action chip (Approved, Submitted, etc.), and optional metadata (status change, acting-for manager, approval comment).

Pagination uses server-side pageInfo.hasMore — use prev/next at the bottom of the trail. Delegate actions display Acting for {name} when metadata includes acting-for fields.
