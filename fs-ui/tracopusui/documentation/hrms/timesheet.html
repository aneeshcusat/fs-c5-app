Overview

HRMS → Time Sheet is the weekly hour grid. When timesheet approval is enabled, submit and manager review apply — see the Approval guide. Sync external leaves when integrations allow.

How to use

1. Open the current week
Confirm week range in the header.
2. Log hours daily
Prefer daily entry over Friday catch-up.
3. Link billable work
Select the correct project/deliverable.
4. Submit if required
Follow Timesheet Approval when the workflow is on.
