The job of this console

Log the week, pass validation, submit if the org requires approval, and stop editing when the period locks. Leave hours should follow approved leave, not a parallel guess.

Seat at the table

Employees fill their grid. Managers approve. Finance and payroll consume after lock. Project managers do not treat this as a task tracker.

The working rhythm

Pick the week, enter hours against work items, validate, submit, then wait for approval if enabled. Fix rejects on the same week. Do not invent a project code that does not exist.

Moments that bring you here

Friday fill. A week with leave in the middle. Validation blocking overtime. Before payroll lock. After a project code change.

ⓘ
Protected production flow
Entry, approval, and locking stay on the live timesheet engine. Intelligence hooks may advise; they do not replace the grid as source.

Overview

HRMS → Time Sheet is the weekly hour grid. When timesheet approval is enabled, submit and manager review apply — see the Approval guide. With partialWeekSubmissionEnabled on, you can submit selected days as separate batches while leftover draft days stay editable; with the flag off (default), submit covers the whole week. Sync external leaves when integrations allow.

When Work-Time Governance catalog features are effective, a governance banner can appear for validation, late bands, or lock policy. With timesheet.reminders or timesheet.late-workflow on, the page loads a server deadline preview for the selected week (it does not guess Friday 18:00 locally). When late-workflow requires a reason, Submit shows a late-reason field. Submit still uses this grid — governance does not add a second timesheet.

How to use

1. Open the current week
Confirm week range in the header. Changing week or team refreshes the deadline preview.
2. Log hours daily
Prefer daily entry over Friday catch-up.
3. Link billable work
Select the correct project/deliverable.
4. Check deadline / late reason
If the week is past the configured cut-off and late-workflow is on, complete the late-reason field before Submit (Other needs detail).
5. Submit if required
Full week when partial is off; use day chips to submit batches when partial is on. See Timesheet Approval.
