Overview

These screens manage legal calendars, working-day rules, holiday import batches, and calendar impact preview. They feed the same resolver used by Leave Management. Holiday import is operator-assisted; use People Holidays for bulk holiday maintenance. Create/update via forms when available, or API.

How to use

1. Maintain holidays
Use People Holidays for bulk; holiday import here is operator-assisted (batch review), not full self-serve auto-import.
2. Working-day rules
Review jurisdiction patterns; create/update via forms when available, or API.
3. Impact preview
Inspect calendar impact preview when sample ranges are available.
4. Assign / publish calendars
Publish calendar versions via available forms; map jurisdictions and verify leave day counts.
