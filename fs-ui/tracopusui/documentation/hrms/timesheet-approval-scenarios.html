Happy path (status → work items)

1

Save draft

Week stays DRAFT / REOPENED / REJECTED. Days → DRAFT. Work items unchanged.

2

Submit / Resubmit

Week → PENDING_APPROVAL; clears prior approvedBy / rejection; REJECTED lines reactivated to ACTIVE. Work items not yet written (or remain demoted).

3

Approve

Week → APPROVED. promoteWeek upserts TIMESHEET activities; leftover PENDING/DRAFT days cascade to APPROVED; orphans soft-deleted.

4

Reopen / Unlock

Week → REOPENED; days → DRAFT. demoteWeek soft-deletes live TIMESHEET activities. Who: recorded approver, or manager if AUTO, or solo owner with no manager.

5

Edit + Resubmit

Week → PENDING again; approval fields cleared. Work items stay demoted until next approve.

6a

Approve again

Revive/upsert via day.taskActivityId / natural key; soft-delete orphans.

6b

Reject

Week/days → REJECTED. demoteWeek ensures no live TIMESHEET hours remain.

Work-item reflection

On approve — promote

TimesheetPromotionService.promoteWeek writes TaskActivity with source=TIMESHEET, links day/week ids, approvalStatus=APPROVED. Soft-deletes orphans not kept. After demote, revive uses day.taskActivityId.

On reject / reopen / unlock — demote

demoteWeek soft-deletes live TIMESHEET activities for the week. Non-TIMESHEET sources (TASK_BOARD / LEGACY) are left alone. Day links kept for revive.
