Overview

Bidding, roster planning, and coverage optimizer screens are registers for seasonal leave planning data. Formal leave still goes through Leave Management. No self-serve write UI — seed via API.

How to use

1. Open bidding
Admin → Leave → Bidding — review quota windows and bids.
2. Review roster rules
Inspect coverage rules; create/update via API.
3. Coverage preview
Inspect optimizer preview when data is seeded.
4. Formal leave
Employees still apply via Leave Management for approved windows.
