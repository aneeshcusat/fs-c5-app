Overview

People → Holidays is the source calendar for non-working public days. Leave Configuration maps jurisdiction → calendar key so day counts stay correct across regions.

How to use

1. Create holidays for the year
Add national and regional days with consistent location keys.
2. Map in Policy Center
Assign calendar keys under Calendars in Global Leave Policy Center.
3. Assign employees
Ensure employees have jurisdiction (or working-day overrides) as needed.
4. Spot-check leave apply
Apply leave across a holiday and confirm the day is excluded.
