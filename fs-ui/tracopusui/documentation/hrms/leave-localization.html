Overview

Leave localization keeps region-specific wording aligned with legal calendars and policy packs. This screen is a register only — no self-serve write UI; seed via API.

How to use

1. Open Localization
Admin → Leave → Localization.
2. Review locale packs
Inspect packs and translations; seed or update via API.
3. Check jurisdictions
Confirm packs align with countries used in Policy Center.
4. Spot-check Leaves
When packs are live, verify copy as a test employee.
