Overview

Admin → Persona navigation is the simplified org editor for access kill switches and per-page persona maps. Role-level “who may use a persona” still lives on Roles & permissions. Protected paths (Roles, Persona navigation, App Config, Setup checklist) cannot be turned off.

Evaluation order: role menu flags → role personaModules → org pagePersonaMap when present → org disable lists (always win).

How to use

1. Enable the screen
Confirm personaNavigationEnabled (or Roles access) for your admin role.
2. Turn off what the org should not see
On Turn off, disable personas, modules, or search and turn individual pages Off.
3. Customize a page when needed
On Page access, select a route, choose Custom, toggle personas, then Save.
4. Verify with a test user
Sign in as a non-admin persona and confirm menus and deep links match the policy.
