Overview

Document rules, review, and retention keep medical and legal evidence on a controlled lifecycle. These screens are primarily registers; create/update via forms when available, or API.

How to use

1. Open document rules
Admin → Leave → Document rules register.
2. Review or update rules
Create/update via forms when available, or API.
3. Document review queue
Inspect pending reviews; act via forms when available, or API.
4. Retention register
Inspect retention rows; schedule changes via forms when available, or API.
