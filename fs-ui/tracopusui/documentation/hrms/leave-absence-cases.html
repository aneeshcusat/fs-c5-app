Overview

Absence cases extend ordinary leave when HR needs a structured case file, documents, and return-to-work steps. Screens are primarily registers; create/update via forms when available, or API.

How to use

1. Open the absence register
Admin → Leave → Absence cases.
2. Review or update a case
Open case detail; create/update via forms when available, or API.
3. Check documents
See Leave documents for evidence rules and review queues.
4. Return-to-work register
Inspect clearance status; update via forms when available, or API.
