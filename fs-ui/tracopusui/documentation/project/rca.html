Projects → Root cause analysis Route /project/rca Org flag rcaEnabled Manager · Project Manager · Executive · Admin

The job of this console

Link the incident, record causes, spawn actions, write a lesson if required. Keep people-sensitive data out.

Seat at the table

PMs, executives, admins. Not a substitute for HR performance files.

The working rhythm

Open after an incident, write, assign actions, close RCA when causes are agreed.

Moments that bring you here

Sev incident. Repeat defect. Customer escalation. Audit of a miss.

ⓘ
Analysis, not the action log
Owners and due dates belong on issues/tickets. Mask snippets for AI and graph.
