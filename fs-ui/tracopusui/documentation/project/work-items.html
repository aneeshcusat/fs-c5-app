Work Items

Track fine-grained activities including assignees, statuses, estimates, and logged effort.

Granular activity register under a deliverable, tied directly to timesheet and planner workflows.

Overview

Work items are the smallest planned unit under a deliverable and typically map to daily execution and time logging.

Screen layout

Header: Create work item, filters, sorting, search.
Body: Work item rows with type, priority, owner, duration, and status.

Header & filters

Use status/priority filters and team selections where available to focus execution queues.

Summary & charts

Activity-level charts and popovers can show logged vs planned hour patterns for selected records.

Main content & actions

Use row actions to update status, assign team members, and open detailed activity records.

Who uses this screen

Delivery leads and contributors managing activities across projects — register view with bulk actions and type/status analytics.

ℹ️
Activity register
Alternative to taskboard for dense filtering and bulk updates — same underlying work items.

Key concepts

Work item register

Activities with project, deliverable, assignee, status, priority, type.

CREATE work item

New activity with checklist support and deliverable link.

Bulk actions

Multi-select status or assignee changes — PM permission.

Summary analytics

Type and status distribution charts in strip.

Checklist support

Sub-steps on activities tracked in activity charts.

Common mistakes

⚠️
Bulk assign without notification check
Assignees miss new work — confirm notify on bulk bar.
⚠️
Activities without project
Non-project work skews taskboard billable donut — link project when billable.
⚠️
Ignoring checklist
Checklist progress donut stays red — break work into checkable steps.

FAQ

Work items vs task-activity?

Same entities — work-items emphasizes register; task-activity adds five chart types.

Taskboard difference?

Kanban columns vs table — edits sync instantly.

Can I import activities?

Bulk import via admin/integration — not from UI register.

Checklist limits?

Org config — typically unlimited items per activity.
