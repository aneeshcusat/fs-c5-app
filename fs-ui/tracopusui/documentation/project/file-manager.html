File Manager

Manage project-related files with list/grid views, type filters, and pagination.

Workspace file navigation with folder hierarchy, filters, sorting, and sharing context.

Overview

File Manager is an access-controlled page for browsing and organizing workspace files.

Screen layout

Layout: Folder tree, breadcrumb, and content panel.
Views: List and grid.
Controls: SHOW and SORT with pagination.

Header & filters

SHOW: All · Folders · Files · Shared · Mine
SORT: Name · Date · Size

Summary & charts

Summary KPIs provide storage and type distribution context for current scope.

Main content & actions

Use folder navigation and filters to quickly locate files, then open from project detail Files tab when scoped to a single project.

Who uses this screen

Project teams storing and sharing delivery documents — folder tree, upload, preview, and folder-level permissions within project scope.

ℹ️
Project document hub
Prefer file-manager over chat attachments for version-controlled deliverables clients may audit.

Key concepts

Folder tree

Hierarchical browser scoped to project context.

Upload

Drag-drop or file picker — multiple files.

Preview

Inline preview for PDF, images, office formats.

Folder permissions

Restrict subfolders to roles or individuals.

Project link

All files scoped to active project — switch project in header.

Permissions

RoleAccess on this screen

📝
Administrator override
Org administrators and service accounts configured in the Admin console may bypass row-level scopes shown above. When in doubt, confirm access with your Tracopus administrator.

Common mistakes

⚠️
Sensitive data in root folder
Default member read — use restricted subfolders for finance/legal.
⚠️
Chat as document store
Attachments lost in scroll — move final files to file-manager.
⚠️
Duplicate filenames
Overwrite rules vary — use version suffix convention.

FAQ

Storage limits?

Org quota — error on upload when exceeded.

Version history?

May be integration-dependent — not always native.

Cross-project files?

No — copy manually or use shared account folder if exists.

Mobile upload?

Mobile may view — upload typically web.
