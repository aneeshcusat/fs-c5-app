Delivery Sprints

Sprint slices on existing tasks and work items — timeboxes, not a second backlog product.

Scroll to Flowcharts. Scenario: Plan a delivery sprint from existing tasks.

Timeboxes

Sprints on work you already broke down

Delivery sprints are windows over Task and TaskActivity. The backlog is still the project’s deliverables.

Projects → Delivery sprints Route /project/delivery Org flag activitesEnabled Manager · Project Manager · Resource Manager · Executive · Admin

The job of this console

Pick a window, include real tasks, run the sprint, complete on board or work items.

Seat at the table

PMs and managers with activitesEnabled. Contributors execute the items; they may not author the sprint.

The working rhythm

Set window, pull work, stand up on the board, close the sprint against the same tasks.

Moments that bring you here

Sprint planning. Mid-sprint slip. After a scope cut. When Gantt looks too long for a two-week talk.

ⓘ
Timebox, not a new WBS
Deliverable = Task. Work item = TaskActivity. Sprints do not fork those tables.
