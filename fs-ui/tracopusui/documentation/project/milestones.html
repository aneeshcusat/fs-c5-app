Milestones

Named delivery dates on a project — governance markers, not a replacement for Task deliverables.

Scroll to Flowcharts. Scenario: Add a milestone on a project.

Named dates

Markers on the project, not a second WBS

Milestones name important dates on a Project. The work that hits them is still Task / TaskActivity.

Projects → Milestones Route /project/milestones Org flag milestonesEnabled Manager · Project Manager · Executive · Admin

The job of this console

Place and maintain milestone dates, link work if you can, and keep Gantt and governance in agreement.

Seat at the table

PMs, executives, admins. Contributors execute tasks toward the date.

The working rhythm

Filter project, add or shift a milestone, confirm Gantt, check related tasks.

Moments that bring you here

Kickoff. Customer gate. Go-live. After a slip that moves the flag.

ⓘ
Not a deliverable
Deliverable means Task. Milestone is a date marker on the project.

Overview

Milestones are governance dates on Project. Deliverables (Task) remain the work. NPD gates are product-development gates.

How to use

1. Dates here, work on tasks
A milestone without tasks is a flag, not a plan.
