Chat

Coordinate with teammates through threaded messaging and conversation panels.

Internal messaging with contact lists, group threads, and integrated header previews.

Overview

Chat provides workspace messaging for project coordination and quick context exchange.

Screen layout

Layout: Conversation list on left, message thread on right.
Entry points: Full chat page and header recent-threads dropdown.

Header & filters

Thread selection and search controls help narrow active conversations.

Summary & charts

Unread/recent indicators surface conversation activity; no heavy chart analytics on this page.

Main content & actions

Open thread, review context, post updates, and continue delivery coordination without leaving the workspace.

Who uses this screen

Project teams communicating in channels and DMs — threads, mentions, attachments within Tracopus Luxury UI collaboration layer.

ℹ️
Team messaging
Use channels per project or workstream — decisions with lasting value should move to notes or file-manager.

Key concepts

Channel list

Project and team channels with unread badges.

Direct messages

1:1 conversations outside channel noise.

Thread replies

Reply in thread to keep channel readable.

Attachments

Share files inline — prefer file-manager for final docs.

Mentions

@user triggers notification per user prefs.

Common mistakes

Lost after scroll — copy to pinned note.

@channel abuse

⚠️
Sensitive files in DM
Same retention as channels — use restricted file-manager folders.

FAQ

Chat vs email?

Chat for fast team coordination; client formal comms often email outside Tracopus.

Retention policy?

Org admin sets — may delete after N days.

Mobile chat?

Push notifications via mobile app if enabled.

Integrations?
