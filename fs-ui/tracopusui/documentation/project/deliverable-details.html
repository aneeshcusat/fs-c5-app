Common mistakes

⚠️
Editing estimate after work started
Distorts variance history — use change log note for audit.
⚠️
Work items not linked
Hours booked to project only miss deliverable variance — link activities.
⚠️
Documents only in chat
Formal sign-offs belong in Documents tab.

FAQ

How to improve est vs actual?

Log hours to deliverable on timesheet; keep estimate current.

Can I split deliverable?

Create child deliverables under same project — no automatic split.

Who sees documents?

Project members with file permission — same as file-manager rules.

Blocked status?

Use when waiting on client — excludes from on-track timeline metrics if configured.
