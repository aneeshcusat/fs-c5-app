Global Search

Find entities quickly when exact location is unknown, instead of browsing multiple lists.

Workspace-wide search across projects, tasks, and related records with permission-aware results.

Overview

Global Search indexes records you can access and is optimized for quick cross-module lookup.

Screen layout

Input: Header search entry.
Output: Result groups with navigable links into projects, tasks, and related entities.

Header & filters

Search is permission-aware; inaccessible records are not returned.

Summary & charts

Result grouping and relevance help prioritize exact title matches and keyword-adjacent hits.

Main content & actions

Open result links directly to destination pages and continue with scoped operational actions.

Before you start

💡
Cmd+K habit
Train muscle memory — faster than sidebar for known project names.
ℹ️
Permission boundary
Search never shows records your role cannot open directly.

Who uses this screen

Power users finding projects, tasks, people, files, and notes across Tracopus — global search with type filters and keyboard shortcut.

ℹ️
Cross-module discovery
Faster than navigating registers when you know a keyword — use type filters to narrow results.

Key concepts

Global search

Single query box searches projects, tasks, people, files, notes.

Type filters

Limit to entity type after initial query.

Recent searches

Re-run prior queries from dropdown.

Keyboard shortcut

Focus search from anywhere in web app (typically Ctrl/Cmd+K).

Permission-aware

Results only include records your role may view.

Permissions

RoleAccess on this screen
All authenticated usersSearch within permission scope.

📝
Administrator override
Org administrators and service accounts configured in the Admin console may bypass row-level scopes shown above. When in doubt, confirm access with your Tracopus administrator.

Common mistakes

Incomplete index — wait for app shell ready.

Too-broad single char
Performance — type full keyword.

Expecting hidden private projects

FAQ

Does search include chat?

Org config — often messages excluded or limited.

Mobile search?

Mobile has scoped search — not full global index.

Search syntax?

Quotes for exact phrase on some deployments.

Index delay?

New records appear within minutes — not always instant.
