Overview

Templates control outbound messaging for workspace events (approvals, notifications, and related workflows). System templates ship with the product; custom templates and overrides depend on org configuration.

How to use

1. Prefer overrides over forks
Adjust the existing event template when possible so keys stay aligned with the backend.
2. Keep placeholders intact
Do not rename merge fields unless the event contract supports them.
3. Preview every change
Broken HTML or empty subjects are the most common failures.
4. Test with a real event
Trigger a sandbox approval or notification after saving.
