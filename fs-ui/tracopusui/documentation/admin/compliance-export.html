The job of this console

See which evidence families are ready, run an export, and hand the pack to audit. Fix gaps in the owning consoles (retention, audit, policies), then re-export. Do not edit the pack as if it were a source.

Seat at the table

Administrators preparing an audit. External auditors receive the file; they do not open this console.

The working rhythm

Read readiness, close gaps on source consoles, export, store the file in the audit binder. Repeat when the window changes.

Moments that bring you here

SOC or customer security questionnaire. Year-end. After a retention hold. When a previous pack is stale because flags or policies changed.

ⓘ
Export is a snapshot
The pack is not a second system of record. If a number looks wrong, fix Employee, policy, or audit at source and export again.
