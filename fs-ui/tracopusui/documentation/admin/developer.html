Extensibility hub

Apps, keys, and webhooks from one door

The developer portal is where you register apps, review usage, then manage API keys and webhooks. It is the hub; the key and webhook registers are the sharp tools.

Admin → Developer portal Route /admin/developer Org flag developerPortalOverviewEnabled HR Admin · Org Admin · integration owner

The job of this console

Register an app, understand usage, then issue keys or subscribe webhooks without scattering credentials in chat. Revoke from the same hub when an integration leaves.

Seat at the table

Administrators and named integration owners. Ordinary employees do not open the portal. External vendors receive credentials once, not a login to this console.

The working rhythm

Open the hub, add or select an app, jump to API keys or webhooks, complete the issue or subscription, store the secret offline. Review usage when a partner says they are throttled.

Moments that bring you here

First connector. A vendor rotation of secrets. After a leaked key. When webhook delivery failures pile up.

ⓘ
Secrets are shown once
The portal stores metadata, not a recoverable plaintext vault. If a secret is lost, revoke and issue again.
