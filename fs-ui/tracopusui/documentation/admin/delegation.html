Acting for someone else

Coverage for attendance, timesheet, and leave — not a standing proxy

Delegation rules name outgoing delegates and the managers you are acting for, scoped to attendance, timesheet, and leave. A delegate sees those items in My Approvals for the window you set.

Admin → Delegation rules Route /admin/delegation Org flag delegationEnabled HR Admin · Org Admin · Manager (own outgoing)

The job of this console

Record who covers whom, for which domain, and until when. Stop a delegate the day the manager returns. Do not use this as a permanent second manager — that belongs in org structure.

Seat at the table

Administrators configure org-wide patterns. Managers typically set their own outgoing delegate. Employees do not delegate approval authority from this console.

The working rhythm

Open the register, add an outgoing delegate or an acting-for row, pick domains, set dates, save. Confirm the delegate sees the inbox. End the row when coverage stops.

Moments that bring you here

Leave of a people manager. End-of-year freeze when approvers travel. A new skip-level who should not inherit every domain. After mistaken standing proxies, to unwind them.

ⓘ
Delegation rides on ApprovalAuthority
This is not a parallel approval engine. Live requests still follow published policies; the delegate is a temporary actor on that path.

Overview

Delegation is a workflow overlay on ApprovalAuthorityService. It does not rewrite the underlying timesheet, leave, or attendance records.

How to use

1. Keep windows short
Open-ended delegates are hard to audit.
2. Match policy domains
A leave-only delegate cannot approve timesheets.
3. Check acting calendar
Overlaps are visible on the calendar panel.
4. Confirm after login
Delegates may need a refresh to see the acting banner.
