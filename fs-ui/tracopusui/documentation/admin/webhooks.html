Outbound events

Subscribe, inspect deliveries, retry a miss

Webhooks subscribe to domain events, show delivery attempts, and retry failures. They push what already happened on Employee, leave, ticket, and similar records.

Admin → Developer portal → Webhooks Route /admin/webhooks Org flag webhooksEnabled HR Admin · Org Admin · integration owner

The job of this console

Subscribe an endpoint, verify signatures on the partner side, watch deliveries, and retry a failed batch. Pause or delete a subscription that is flooding a dead URL.

Seat at the table

Integration owners with Admin access. Endpoint servers are outside Tracopus; this console only manages the subscription.

The working rhythm

Add a subscription, send a test if offered, watch the delivery log, retry failures, disable when the partner is down for a long window.

Moments that bring you here

Go-live of a connector. A spike of 4xx/5xx. After rotating an endpoint URL. When automation also notifies and you must avoid double fire.

ⓘ
Webhooks are not the system of record
A missed delivery does not mean the leave or ticket vanished. Retry the push; do not recreate the source row.
