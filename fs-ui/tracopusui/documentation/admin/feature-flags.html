Pilot and catalog control

Turn surfaces on without shipping a build

Feature flags are the live catalog of org toggles, including Work-Time Governance families on the same console. A flag change is how a pilot sees a menu tomorrow without a deploy — and how you take it back just as fast.

The job of this console

Stage a pilot, watch adoption, and govern high-risk toggles. Enable for an org unit before global on. Read dependents so a child never appears while its parent is off. Use the Work-Time Governance panel for timesheet, approval, and attendance catalog families — not a separate route.

Seat at the table

Only administrators who can open Admin and whose org has featureFlagsEnabled. Contributors never see this register. Persona navigation still decides who sees a page after the flag is on.

The working rhythm

Filter by module and status, open a flag, enable for a pilot, save, then log in as a test persona and confirm menus. Rollback by disabling. Coordinate Application Config keys and role permissions when a flag alone is not enough.

Moments that bring you here

A new module is ready for one country. Work-time rules must go live before payroll lock. A flag caused a bad menu and needs an immediate off. Before go-live, to confirm dependents are unblocked.

ⓘ
Flags gate menus; they are not Application Config
Lists, calendars, and master values still live in Application Config. Roles still decide who may open a gated page. Turn the flag on, then finish config and persona access.

Overview

This console is the live catalog of org feature flags. The Work-Time Governance panel on the same page turns catalog families on or off in Application Config — it is not a separate route.

How to use

1. Prefer pilots before global on
High-risk flags should ship to a pilot org unit first.
2. Read dependents
Blocked children stay off until the parent flag is enabled.
3. Coordinate with config
Some flags still need Application Config keys or role permissions.
4. Use Work-Time Governance for time rules
Approval chain, timesheet validation, and attendance catalog live in the WTG panel below the register.
