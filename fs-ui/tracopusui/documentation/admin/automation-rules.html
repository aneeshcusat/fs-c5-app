Graph editor

Trigger, condition, action — drafts stay silent

Automation rules is the graph editor: trigger → condition → action. Save drafts, then publish from the studio. A draft never fires against live events.

The job of this console

Build or edit the graph, keep a draft until the path is right, then return to the studio to publish. Pause a live rule in the studio before you reshape it here.

Seat at the table

The same administrators who own Workflow studio. Contributors do not get a builder. Partners should not receive export of graphs with production URLs without review.

The working rhythm

Open a rule, edit trigger and conditions, attach actions (notify, route, connector), save draft, publish from the studio. Use notification templates for copy.

Moments that bring you here

A new leave type needs a follow-on mail. An SLA breach should open a ticket. After a connector change. When a published graph mis-routes and must be paused first.
