The job of this console

Orient an administrator to the right how-to before they touch live org data. Scan the list, open the screen that matches the menu they are about to use, and follow that page’s flowcharts instead of guessing across modules.

Seat at the table

Written for people who can open Admin in the product, plus implementation partners setting an org for the first time. Employees and managers do not need this hub for day-to-day work.

The working rhythm

Start here only when you do not know which console owns the change. Pick a screen, read its briefing, then work in the app with the Guide button as a spare copy of the same page.

Moments that bring you here

Day-one setup. A new HR admin asking where flags live versus Application Config. After a release, when a menu moved under Admin. Never as a substitute for the live register.

ⓘ
Hub, not a source of truth
Nothing on this index writes Employee, Project, or Application Config. Follow each console’s own note for what it is allowed to change.

How to use these guides

From any Admin screen, the book icon in the page hero opens the how-to for that route. Leave-admin screens (policies, test lab, calendars) live with the HRMS leave guides because they share those source services. For every module’s Guide pages, use the searchable All screen how-tos index.
