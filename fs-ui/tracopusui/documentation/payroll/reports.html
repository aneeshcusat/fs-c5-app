Payroll Reports

Permission-scoped payroll exports — snapshots of runs and slips, not a ledger you type into.

Scroll to Flowcharts. Scenario: Export a payroll register snapshot.

Payroll export

Snapshots of cycles you already ran

Payroll reports export run and paycheck data. The file is not a new payroll engine.

The job of this console

Pick period, export, fix the run if totals are wrong, export again.

Seat at the table

Payroll, finance, executives as allowed. Employees do not export org registers.

The working rhythm

Run report, export, secure the file.

Moments that bring you here

Bank file. Statutory return. Audit. After a recast run.

Sensitive snapshot
Masking applies. Do not drop CSVs into Work Graph or tickets.
