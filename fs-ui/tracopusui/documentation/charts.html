Charts & Analytics

Complete reference for every chart and visualization in the Luxury UI — what type it is, what data it uses, and how to interpret it for decisions.

Visual types explained

Web charts render via ApexCharts unless noted. Mobile Insights uses fl_chart with matching Lux card styling.

TypeBest forHow to readWhere used
DonutPart-to-whole ratiosEach slice = category share; center label often shows total or primary metricStatus mix, billing split, portfolio outcomes
Bar (H/V)Ranking categoriesLonger bar = higher count; horizontal for long labelsTop accounts, teams, priorities, skills
AreaTrends over timeFilled line shows volume; slope = growth/declineCreation trends, daily load, joins/exits
LinePrecise time seriesFocus on rate of change between pointsHeadcount trend, velocity, billable trend (mobile)
FunnelStage progressionWidth at each stage = volume; narrowing = drop-offBid, PO, project, taskboard pipelines
HeatmapTwo-dimensional intensityDarker cell = higher valueDeadline heatmap, roster heatmap
RadarMulti-axis comparisonShape shows strengths/weaknesses across dimensionsPersonal performance radar
TreemapHierarchical shareRectangle area = proportionGrade/band, portfolio effort map
Bubble / ScatterCorrelation + sizePosition = X/Y metrics; bubble size = third dimensionRisk scatter, estimate vs completion
Radial barProgress toward maxArc fill = % of capacity or completionStatus radial, mobile progress ring
Stacked barComposition over timeSegment height = sub-category within totalHours by type, mobile daily hours
Dual lineTwo series comparisonGap between lines = variancePlanned vs logged hours (mobile)
Gauge / Dual gaugeSingle KPI %Fill arc to target thresholdMobile utilization & billable target
CSS segment barSimple status mixColored segments without chart libraryInvoice status bar
Filters affect all charts: Summary charts always reflect the current list filters (teams, SHOW preset, date range, text filter). Change filters to see charts recalculate for that slice.

Manager delivery lens highlights

Risk scatter (bubble)

Bubble

X/Y position maps risk dimensions; bubble size = project effort or exposure. Outliers in the "high risk" quadrant need executive attention.

Deadline heatmap

Heatmap

Rows = teams or owners; columns = time buckets; color intensity = count of deadlines due. Dark clusters indicate scheduling crunch periods.

Velocity line

Line

Completed deliverables or projects over time — trend line slope reflects delivery throughput.
