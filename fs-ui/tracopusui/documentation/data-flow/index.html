Schedulers referenced in simulators

LEAVE_ACCRUAL

Monthly (1st, 06:00) — credits entitlements from published policy or classic config; idempotent ledger rows with periodKey=yyyy-MM.

LEAVE_CARRY_FORWARD

Daily scan — applies carry-forward caps and fiscal/calendar lapse rules from rules_json.

LEAVE_PROMOTION_RETRY

Every 15 min (optional) — retries failed TaskActivity promotion after leave approve.

APPROVAL_SLA_REMINDER

Daily reminder emails for SUBMITTED leave / pending approvals when org reminder flag is on.

Frequently asked questions

Do flag toggles change my workspace?

No. Simulators are read-only learning tools in the documentation site. They show what would happen if flags were ON or OFF — they do not call your Tracopus backend.

Which simulator should I open first for leave go-live?

Start with Leave policy & accrual (publish policy, import opening balances, verify accrual job), then Leave request & approve for the employee/manager workflow.

Where is SQL in the simulators?

Each step in the Table data flow tab includes representative SQL blocks and sample row tables showing column values before/after the step.

How do simulators relate to Application Config?

Org flags come from modules.HRMS.configurations.leaveAdditional (and related paths). See Application config reference for the full key list; simulators show runtime effect per flag.
