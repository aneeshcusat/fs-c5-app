How to use this catalog
Search or filter by module, then open a page card. Each entry includes scenarios, permissions, prerequisites, numbered create/use steps, API Documentation (sample curl + related APIs), verification checklist, and implementation notes. Pair with the Scenario User Guide for QA scripts and the screen docs for UI reference — links go both ways.
