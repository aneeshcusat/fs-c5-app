Seat at the table

The working rhythm

Moments that bring you here

New project kickoff. A change request. After a bid win. When a plan is still a blob of text.

Overview

WBS assistant drafts structure for a Project. Canonical work remains Task (deliverable) and TaskActivity (work item). It does not create NPD ideas or a second WBS table.

How to use

1. Accept is a write

2. PO chain

3. Mask client secrets
