📱 Mobile App User Manual

This page is the complete guide for using the Famstack mobile app, including first-time registration (signup flow), QR/barcode-based login setup, PIN and biometric login, and daily usage for tasks, projects, and timesheet entry.

Who should read this: End users, project team members, and administrators onboarding users to the mobile app.

✅ Prerequisites

Before you start

  • You must have an active Famstack account (email/user ID managed by your organization).
  • Your organization must enable mobile access and device registration permissions.
  • Install the Famstack mobile app on your Android/iOS device.
  • Keep your web app session open to generate the registration QR code.
📌 Note: In this system, first-time mobile "signup" is done through device registration from the web app (not a public self-signup form).

🆕 Signup / Device Registration Process

Mobile app onboarding is a secure device registration flow linked to your existing web account.

Step-by-step

Step 1: Log in to Famstack Web
Sign in with your email and password (or Microsoft SSO if enabled).
Step 2: Open Mobile Registration
Click the mobile registration icon (phone + QR indicator). This icon appears only when:
  • Device registration is enabled in profile/settings controls
  • Your user has device app access enabled
  • Your device is not already registered
Step 3: Open the mobile app
Launch the app and go to User Login.
Step 4: Scan the QR code
Use the QR scanner icon in the mobile login screen to scan the web-generated code.
Step 5: Create your 4-digit PIN
After successful registration/authentication, set a 4-digit unlock PIN (mandatory for quick login).
Step 6: Optionally enable biometric login
If supported on your device, you can enable fingerprint/face unlock immediately after PIN setup.

🔳 QR / Barcode Generation and Scan Details

How the web app generates the QR code

The web app creates a registration URL using backend endpoint + device registration path + your user parameters (`emailId` and `userId`). This URL is rendered as a QR code in the mobile registration popup.

What happens when mobile scans the QR code

  • The mobile app reads the QR value (URL or path).
  • It extracts `emailId` and `userId` from query parameters.
  • It registers your device with a generated unique device ID.
  • It authenticates using the registered email + device ID and stores auth token/team info securely.
⚠️ Important: If the QR code does not contain valid `emailId` and `userId`, registration fails with "Invalid QR code."
💡 Tip: If your QR provides a full host URL, the mobile app updates API host settings from that QR so users can connect to the correct environment automatically.

🔐 Complete Login Process

Available login methods

Method When to use Requirements
User Login First-time setup or fallback login Email + user ID/password flow from org setup
QR Login Recommended first-time setup Web-generated registration QR
4 Digit PIN Daily quick login PIN must be created after first successful login
Biometric Fastest login after onboarding PIN setup + device biometric support + enrollment enabled

First-time login flow (recommended)

1) Open mobile app → use User Login or scan QR code.
2) After success, set your 4-digit PIN.
3) Optionally enable biometric unlock.
4) You are redirected to the Tasks screen.

Returning user flow

  • If PIN exists: use the 4 Digit PIN tab.
  • If biometric is enabled and supported: biometric login can be auto-attempted.
  • If secure data cannot be read: use User Login or QR again to re-register session data.

🚀 After Login: Main Navigation

Primary mobile areas

Tasks

Week-based task activity list with filters (Completed, Ongoing, Assigned, All), search, and pull-to-refresh.

Projects

Project list with filters (Active, Archive, My Projects, Favorites), search, and details.

Timesheet

Daily and weekly hours summary with entry capture for billable, non-billable, and leave/holiday time.

⏱️ Timesheet Entry (Mobile)

Daily categories

  • Billable Time: Project + deliverable + category + work item + hours.
  • Non Billable Time: Division, account, client partner, requesting team, category, work item, hours.
  • Leave / Holiday: Work item (default LEAVE) + hours.

Entry process

Step 1: Open Timesheet from Tasks/Projects floating action button.
Step 2: Select week/day and open the relevant section.
Step 3: Tap +, fill required fields, then tap Save.
Step 4: Confirm success toast; totals refresh in summary.

📋 Tasks and Projects Usage

Tasks screen highlights

  • Search by task name (3+ characters).
  • Filter by status chips.
  • Tap any task row to open full task detail sheet.
  • Navigate week using left/right arrows.

Projects screen highlights

  • Search by project name, account, or project ID.
  • Filter by Active, Archive, My Projects, Favorites.
  • Tap project row to open complete project detail bottom sheet.

🛠️ Troubleshooting

QR scan fails

  • Reopen mobile registration popup in web app and generate a fresh QR.
  • Ensure camera permission is granted in the mobile OS settings.
  • Check if scanned value includes valid `emailId` and `userId` parameters.

PIN login not available

  • You must complete first-time User Login or QR login first.
  • Set PIN when prompted after successful first login.

Biometric option disabled

  • Device may not support local authentication.
  • OS-level biometrics might not be configured.
  • Enable biometric after a successful PIN-based setup.

Session/token issues

  • Use User Login or QR login again if secure storage data is unavailable.
  • If the issue persists, ask admin to verify mobile/device registration settings.

🔒 Security and Best Practices

  • Do not share your registration QR code with other users.
  • Use a non-obvious 4-digit PIN and avoid reusing ATM PINs.
  • Enable biometric login only on trusted personal devices.
  • If device is lost, report immediately so admin can revoke device access.
  • Always logout if using shared or temporary devices.
