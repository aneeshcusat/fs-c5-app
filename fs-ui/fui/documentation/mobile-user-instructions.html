1. Before You Start

  • You must have an active Famstack user account.
  • Mobile access and device registration must be enabled for your account.
  • Install the mobile app on your device.
  • Keep your web application session available for registration QR generation.
In Famstack, mobile "signup" means device registration against your existing user account.

2. First-Time Setup (Registration / Signup)

Step A: Generate Registration QR from Web App

  1. Log in to the web application.
  2. Open Mobile App Registration from your profile/settings area.
  3. A QR code (barcode) will be shown for your user account.

Step B: Register the Mobile Device

  1. Open the mobile app.
  2. Go to User Login and tap the QR scanner icon.
  3. Scan the QR code from the web app.
  4. After successful registration, set your 4-digit PIN.
  5. Optionally enable Biometric Login (fingerprint/face unlock).
If scanning fails, regenerate the QR code and ensure camera permission is enabled.

3. Login Methods

Login Type When to Use Requirement
User Login First-time setup or fallback Registered account credentials
QR Login First-time onboarding QR from web registration screen
4-Digit PIN Daily login PIN created after first successful login
Biometric Daily quick login PIN setup + supported device biometric

4. Daily Usage

Tasks

  • View task activities by week/day.
  • Use search and status filters (Completed, Ongoing, Assigned, All).
  • Tap a task to view complete details.

Projects

  • View projects and apply filters (Active, Archive, My Projects, Favorites).
  • Use search for project name/account/ID.
  • Tap a project row for detailed information.

Timesheet

  • Add entries under Billable, Non-Billable, or Leave / Holiday.
  • Select date and fill required fields.
  • Enter hours and tap Save.

5. Troubleshooting

  • QR not scanning: Reopen camera, verify permission, and regenerate QR from web app.
  • PIN option unavailable: Complete first-time login and set PIN.
  • Biometric disabled: Enable biometrics in device settings and retry.
  • Login/session error: Use User Login or QR login again to refresh device session.

6. Security Best Practices

  • Do not share your registration QR code.
  • Do not share your PIN with anyone.
  • Enable biometric login only on trusted personal devices.
  • Report lost/stolen devices immediately to your administrator.
