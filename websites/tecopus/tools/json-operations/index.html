Help & Keyboard Shortcuts

Keyboard Shortcuts

  • Ctrl+Z / Cmd+Z - Undo
  • Ctrl+Y / Cmd+Y - Redo
  • Ctrl+F / Cmd+F - Open Search & Replace
  • F3 - Find Next
  • Shift+F3 - Find Previous
  • Esc - Close Search & Replace
  • Ctrl+S / Cmd+S - Download
  • Tab - Indent
  • Shift+Tab - Unindent

Search & Replace Features

  • Match Case: Case-sensitive search
  • Regex: Use regular expressions
  • Whole Word: Match complete words only
  • Replace: Replace current match
  • Replace All: Replace all matches at once

New Features

  • Batch Processing: Process multiple JSON files at once
  • JSON Analysis: Size, depth, and performance metrics
  • Enhanced JSONPath: Query builder with examples
  • More Formats: GraphQL, OpenAPI, Postman, cURL, SQL, MongoDB
  • Code Generators: JavaScript/TypeScript object exports
  • Better Error Reporting: Detailed diagnostics and suggestions
